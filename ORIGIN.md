# Origin of this code

The files in this repository's first commit are the **unmodified** source of
the "SMS Gateway" Flutter/Android app taken from:

    https://github.com/amiralimus/sms_sender.git   (commit f56455dcae8e0e2488819b2971ccb951c0126fe1)

The repository has no licence file. The owner of this project (NM / UpMarket)
states that it is his own SMS project and that he is entitled to build on it.

Everything after the first commit is new work for **NM-Mobile**, the Android
companion app of the NM platform. See README.md / docs/ for what changed.
